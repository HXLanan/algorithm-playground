🧬 最长公共子序列（LCS）

给定两个字符串，求它们最长的公共子序列（不要求连续）。 这是二维动态规划的典范，也是 git diff 和 DNA 序列比对的底层算法。

字符串 A 字符串 B 数据源：本地

DP 表格

状态转移

dp[i][j] = A 的前 i 个字符与 B 的前 j 个字符的 LCS 长度。

若 A[i-1] == B[j-1]：
  dp[i][j] = dp[i-1][j-1] + 1  ← 斜着 +1
否则：
  dp[i][j] = max(dp[i-1][j], dp[i][j-1])

字符相同时，两个指针一起前进（斜着走）； 不同时，扔掉其中一个字符继续比（取上方或左方的较大值）。

它在哪被用到？

🔹 git diff：比较两个版本的文件差异，本质是求 LCS 后标出增删行

🔹 DNA 序列比对：生物信息学中判断两条基因序列的相似度

🔹 拼写纠错 / 模糊搜索：编辑距离（Levenshtein）就是 LCS 的变体

🔹 版本控制、代码合并：三方合并算法的基础

注意区分：子序列不要求连续，子串要求连续—— 后者要用不同的 DP 定义。
