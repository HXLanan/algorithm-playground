# 🎮 Algo Playground —— 算法可视化 + LeetCode 实战平台

一个把「**看得懂算法**」和「**写得出代码**」连起来的本地学习平台：

- 🧩 **25 个算法可视化演示** —— 用动画把抽象算法还原成看得见的过程
- 📝 **71 道 LeetCode 经典题** —— 分类题单、多解法思路、**在线判题**
- 🔗 **双向联动** —— 每道题标注关联的动画演示，每个动画页反查相关面试题

---

## 🧰 技术栈

| 层 | 技术 |
|---|---|
| 后端 | **Python 3**（conda 环境 `mvs_case`）+ **Flask** + flask-cors |
| 架构 | 应用工厂 + **三层分层**：算法层 / 服务层 / 路由层 |
| 前端 | 原生 **HTML5 + CSS3 + JavaScript + Canvas 2D**（无框架、无构建） |
| 判题 | 受限 `exec` + 模块白名单 + 异常隔离（本地学习工具，非生产沙箱） |
| 降级策略 | 后端不可用时，前端 `algo-core*.js` **本地兜底**，页面永不白屏 |
| 大数处理 | Python 原生任意精度 `int`（后端）/ `BigInt`（前端） |

---

## 📐 架构

详细设计见 **[ARCHITECTURE.md](ARCHITECTURE.md)**，核心分层：

```
pages/ + assets/          表现层（页面、样式、动画）
        │ fetch
server/routes/            路由层（Flask 蓝图，HTTP 接口）
server/services/          服务层（参数校验、业务编排）
server/algo/              算法层（纯算法，零依赖，可独立测试）
server/app.py             应用工厂
server/config.py          配置层
```

## 🚀 运行方式

### 1. 安装依赖（在 conda 环境 mvs_case 中）
```bash
conda activate mvs_case
pip install -r requirements.txt
```

### 2. 启动服务（在 algo-playground/ 目录下）
```bash
python run.py
```
然后浏览器打开： **http://127.0.0.1:8080/**

### 3. 免启动方式（可选）
直接双击 `pages/index.html` 也能用——此时前端会自动降级到本地算法，功能完整。
（页面顶部会标注「数据源：本地兜底」）

### 4. 自检（推荐，不需要浏览器）
```bash
python selfcheck.py
```
它会在**不启动 Flask** 的情况下，直接验证算法层与服务层的正确性（排序结果、
麦粒数量、斐波那契数值、遗传收敛、非法参数处理等），全部通过会打印 `ALL PASS ✅`。
